Horizon Kernel AARCH64

Overview

Horizon Kernel is an operating system kernel written in Zig targeting the AARCH64 (64-bit ARM) architecture.

Building and Running on Linux

  1. Install QEMU 
    sudo apt update
sudo apt install qemu-system-arm qemu-system-misc
  2. Install Zig

    Download Zig 0.13.0 or later from ziglang.org and add it to your PATH.

  3. Build the kernel 
    zig build
  4. Run in QEMU 
    zig build run

Building and Running on Windows

  1. Install QEMU

    Open an admin PowerShell prompt and run:

    winget install --id SoftwareFreedomConservancy.QEMU -e
  2. Add QEMU to PATH 
    setx PATH "$($env:PATH);C:\Program Files\qemu"
  3. Install Zig 
    winget install --id zig.zig
  4. Build and Run 
    zig build
zig build run

Project Architecture

  • src/start.zig: Kernel entry point (_start) and main loop.
  • src/mmio.zig: MMIO read/write functions for hardware interaction.
  • build.zig: Zig 0.13 build definition and QEMU run target.
  • kernel.ld: Linker script mapping physical memory address at 0x80000.
